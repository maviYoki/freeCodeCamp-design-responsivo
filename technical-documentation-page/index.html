Introduction to Git

What is Git?

Git is a version control system. It allows you to track changes made to a project over time.

With Git, you can go back to previous versions, create different versions of your project, and work with other people.

Why use Git?

  • Keep a history of the project.
  • Recover previous versions.
  • Work with a team.
  • Create branches for different features.
  • Upload projects to platforms like GitLab and GitHub.

Check if Git is installed with:

            git --version

This command shows the version of Git installed on your computer.

Repositories and Commits

Creating a Repository

A repository is a place where Git tracks the files and changes of a project.

To start using Git in a folder, open the terminal inside the folder and run: 

            git init

Git will now start tracking the folder.

You can check the current state of the repository with:

            git status

The git status command shows which files were modified, added, or are not being tracked yet.

Creating Commits

A commit records a group of changes in the project's history.

First, add the files you want to include:

            git add .

Then, create the commit:

            git commit -m "Add home screen"

A good commit message should briefly explain what was changed.

For example:

            git commit -m "Fix login button"
Branches and Merging

What are Branches?

A branch allows you to create a separate line of development.

This is useful when multiple people are working on the same project.

To create a branch:

            git switch -c feature/login

To switch to an existing branch:

            git switch main

For example:

            
              main
              │
              ├── feature/login
              ├── feature/menu
              └── feature/dialogue

Each team member can work on a feature without directly changing the main branch.

Merging Branches

When a feature is finished, you can merge its changes into another branch. 

            
              git switch main
              git merge feature/login

This adds the changes from the feature branch to the main branch.

Remote Repositories

What is a Remote Repository?

A remote repository is a version of your project stored on a server, such as GitHub or GitLab.

It allows team members to share the same project and synchronize their changes.

Connecting to a Remote Repository

To connect your local repository to a remote repository, use:

            git remote add origin https://github.com/user/project.git

Uploading Changes

To upload your commits to the remote repository, use:

            git push origin main

The git push command sends your local commits to the remote repository.

Working as a Team

Downloading Changes

Before starting work, it is a good idea to update your local repository. 

            
              git switch main
              git pull

The git pull command downloads the latest changes from the remote repository.

Cloning a Repository

If you want to download an existing repository to your computer, use: 

            git clone https://github.com/user/project.git

This creates a local copy of the remote repository.

Basic Team Workflow

  • Pull the latest changes.
  • Create a branch for your feature.
  • Make your changes.
  • Commit your changes.
  • Push your branch to the remote repository.
  • Merge the changes into the main branch.

Example:

            
              git switch main
              git pull
              git switch -c feature/menu
              git add .
              git commit -m "Add menu"
              git push origin feature/menu
